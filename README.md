# Smash Flash DOJO!!! V6
This is a modern, unofficial interpretation of fifth and final iteration of the Smash Flash DOJO!!!, a now closed website for *Super Smash Flash 2* providing information about various aspects of the game through scheduled updates. The project aims to recreate as much of the website as possible while modernizing its content to the most recent version of the game.

Credits to Jake Siegers for creating much of the code used on the previous website.
